# [BEACON Labs - Mobile Security Module](https://sites.google.com/boisestate.edu/beacon-labs/mobile-security-labs)

## [Android State Inference Attacks Lab](/Mobile%20Security/Android%20State%20Inference/)

![Android State Inference Attacks Lab image.](/.images/mobile-security/state.png)

This lab explores security vulnerabillities surrounding API's that allow an attacker to expose state information of a device and its packages. Through social engineering and state monitoring, users will perform a phishing attack to steal sensitive personally identifiable information.

## [Android PHYJacking Attack Lab](/Mobile%20Security/PHYJacking/)

![Android PHYJacking Attack Lab image.](/.images/mobile-security/phyjacking.png)

This lab explores vulnerabilities surrounding physical input sensors and the Android Activity lifecycle. Users will socially engineer a delusive prompt to hijack physical input and authenticate an unauthorized action without the user knowing; all from a zero-permission malicious app.

## [VenomAttack Lab](/Mobile%20Security/VenomAttack/)

![VenomAttack Lab image.](/.images/mobile-security/venom.png)

This lab explores implementing an automated and adaptive activity hijacking method that utilizes hotpatching techniques to identify vulnerable devices and update attack payload without the need for re-installation or re-distribution, hence bypassing offline detection.
