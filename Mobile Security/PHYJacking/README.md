# [BEACON Labs - Mobile Security: Android Physical Input Hijacking (PHYjacking) Attack Lab](https://sites.google.com/boisestate.edu/beacon-labs/mobile-security-labs/phyjacking)

## Type

Mobile Security Lab

## Overview

Nowadays, most mobile devices are equipped with various hardware interfaces such as touchscreen, fingerprint scanner, camera, and microphone to capture inputs from the user. Many mobile apps use these physical interfaces to receive user-input for authentication/authorization operations, including one-click login, fingerprint-based payment approval, and face/voice unlocking.

This exercise implements what is known as Physical Input Hijacking to create unintended authorization with zero needed permissions. Furthermore, we explore weaknesses in existing protection schemes and pitfalls in app implementations. This lab will instruct you on how to make an unsuspecting user provide authorization on an unintended fund transfer through a fake banking application.
