# [BEACON Labs - Network Security Module](https://sites.google.com/boisestate.edu/beacon-labs/network-security-labs?usp=sharing)

## [Off-Path TCP Exploits Lab](/Network%20Security/Off-Path%20TCP%20Exploits/)

![Off-Path TCP Exploits Lab image.](/.images/network-security/off-path.png)

The Global Rate Limit was added in RFC 5961. It opened a vulnerability for off-path attackers to hijack a connection. By maxing out this limit through multiple rounds of sending packets, an attacker can act as a server. This lab explores the implementation of this attack.

## [Middlebox Amplification Attack Lab](/Network%20Security/Middlebox%20Amplification%20Attack/)

![Middlebox Amplification Attack Lab image.](/.images/network-security/middlebox.png)

Reflection based attacks were thought to only be possible through UDP connections. A vulnerability that exploits firewalls makes this possible through TCP connections allowing for a very powerful DDoS attack. This lab walks through the different types of reflection based attacks.

## [Evil Twin Detection Lab](/Network%20Security/Evil%20Twin%20Detection/)

![Evil Twin Detection Lab image.](/.images/network-security/evil-twin.png)

As is trivial to learn the mac address and name of a wireless network, an attacker can then set up a duplicate network that impersonates the legitimate access point known as an Evil Twin. This lab explores software that can be implemented to detect Evil Twins and protect clients.
