# [BEACON Labs - Network Security: Evil Twin Detection Lab](https://sites.google.com/boisestate.edu/beacon-labs/network-security-labs/evil-twin-attack-detection-lab)

## Type

Network Security Lab

## Overview

By creating a legitimate connection to an access point, an attacker can learn the MAC address and name of the network to then create a duplicate network, known as an evil twin, to capture traffic. To a client, the difference between the legitimate access point and the evil twin is imperceptible, thus allowing the attacker to capture potentially sensitive data.

In this lab, we will simulate setting up an evil twin and capturing packets from a client with the program mininet-wifi. Additionally, we will then implement software on the legitimate access point that can analyze network traffic and detect if there is an evil twin.
