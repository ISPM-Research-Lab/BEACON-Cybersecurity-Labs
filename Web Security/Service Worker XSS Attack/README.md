# [BEACON Labs - Web Security: Service Worker XSS Attack Lab](https://sites.google.com/boisestate.edu/beacon-labs/web-security-labs/sw-xss-attack-lab)

## Type

Web Security Lab

## Overview

In this lab, you will learn about the dangerous Service Worker Cross-Site Scripting (SW-XSS) attack and how to defend against it. Cross-site scripting attacks (XSS) are among the most common but dangerous web attacks. Their threat level is increased with software called service workers. Hackers can control these powerful pieces of code and access sensitive information. You will implement a DOM-XSS and SW-XSS attack in this lab to learn how to implement and defend against the SW-XSS attack.
