# [BEACON Labs - Network Security: Middlebox Amplification Attack Lab](https://sites.google.com/boisestate.edu/beacon-labs/network-security-labs/middlebox-amplification-attack-lab?usp=sharing)

## Type

Network Security Lab

## Overview

Reflection amplification attacks were thought to only be possible through the UDP communications protocol before this vulnerability was found in 2021. Using firewall's responses to forbidden TCP packets, a large response of up to infinite packets leaves the server vulnerable to DDoS attacks.  Depending on how the packet is configured, the response size from the firewall scales upwards.

The objective of this lab is to identify the different types of reflection based attacks and interact with a program demonstrating what those responses look like. Additionally, the student should be able to understand and complete Bayesian Nash Equilibrium tables.
