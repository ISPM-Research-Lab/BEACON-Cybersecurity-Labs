# LaTeX Project

This directory contains the LaTeX projects that were used to generate the student instruction manual (under `LaTeX/Instruction-Document`) and the setup document (under `LaTeX/Setup`). It is recommended that instructors seeking to use this lab in their classroom(s) modify the contents of the lab so that it isn't a one-to-one mapping to the original content. By doing so, students will be unable to copy & paste from the publicly available instructor manual if found.
